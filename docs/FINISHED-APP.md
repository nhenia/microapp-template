# Finished-app handoff format

Replace the brackets and remove anything that does not apply. This is a guide, not a claim that testing or deployment happened.

Built [APP NAME]: [one sentence describing its job]. [Live online / saved locally and ready to publish].

[Open app] · [Download files] · [Beginner guide]

The main files are HTML for the screen, CSS for appearance, JavaScript for behavior, and config.js for names, labels and colors. The manifest, icons and service worker support installation and offline use.

To publish free: create a public copy with Use this template, choose Settings → Pages → GitHub Actions, then run Publish micro-app from Actions. Open the address shown in Settings → Pages after the run succeeds.

Tested: [only checks actually completed]. Still to check: [actual limitations, such as installation on the user's phone].
